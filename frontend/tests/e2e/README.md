# 浏览器主流程验收

在仓库根目录准备后端，在前端目录运行：

```sh
cd backend
uv sync --frozen
cd ../frontend
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm build
pnpm test:e2e
```

Linux 缺系统库时使用 `pnpm exec playwright install --with-deps chromium`。默认读取 `backend/.venv` 的 Python（兼容 Windows）；虚拟环境在其他位置时设置 `TRAVELFLOW_TEST_PYTHON` 为 Python 可执行文件路径。

测试自动启动 `127.0.0.1:8137` 的专用后端和 `127.0.0.1:3137` 的生产前端，拒绝复用已占用端口，结束时关闭服务。后端使用独立临时 SQLite 数据库和固定模型、检索替身，不加载 `.env`，不需要真实 API Key，也不接触个人旅行记录。测试种子接口只定义在 `backend/tests/browser_server.py`，不会进入正常应用。

当前共84个场景（42项流程分别在桌面和手机尺寸的 Chromium 运行），覆盖跨轮城市推荐、结构化生成、批量记账与预约、对话修订、刷新、导出、旧文字路书整理、原位费用编辑，以及澄清承接与取消、地点候选与区域选择、导航和预算同步、断网／超时／鉴权错误恢复、后台已记账但回复丢失后的重试和分支草稿隔离；失败记账后先使用快捷建议、快捷建议再次断流及刷新后仍保留原请求号。同日同名同额消费覆盖刷新后选择、连续多项澄清、关联回款、删除保护、草稿保留、预算与导出同步。两天联动覆盖夜间延误预览、刷新后一次应用、固定预约冲突拒绝、条件修改、可选项目精简展示、取消不留部分改动、预算／导出同步及应用回复丢失后的重试。景点搬移覆盖时间轴入口、移入移出、同名选择、刷新取消、双日期展示、预算与账本编辑保留付款日、未知付款日保留、预约／未知交通保护、历史版本及导出同步和应用断流重试。旅行回顾覆盖事实模板、编辑保存、刷新恢复、重复保存、独立导出、未保存文字提示、安全转义、事实变化后保留旧文与历史隔离。旅行照片覆盖上传、重复文件去重、日期地点说明、封面、保存刷新、选择性离线图文导出、移除与历史、错误图片恢复和文字保留。AI写作覆盖草稿不覆盖原文、采用与丢弃、分别保存回忆与朋友圈文案、刷新复制、鉴权失败后手动保存与重试、素材勾选、剪贴板不可用降级及并发版本保护。旅行收尾覆盖结束保留未完成／未结算、归档搜索只读阅读和导出、结束后补记、重新开启、非主方案跳转、分叉状态隔离、相同内容保存及结束回复丢失重试。旅行生涯覆盖按会话去重、城市筛选、统计口径、只读回顾来源、补记跳转、主方案重新开启后采用结束备选、活动补记同步、全部开启后移除，以及空状态、加载失败不冒充零统计和重试恢复。常用偏好覆盖主动保存与刷新、修改、删除保留已有旅行副本和历史、默认不选用、本次对话覆盖／清空、跨窗口冲突保留输入、载入最新核对、保存回复丢失重试、选用内容变化时重选及加载失败继续规划；仅这组操作本机单例偏好的场景通过临时文件锁串行执行，其他流程仍并行。生涯照片与足迹覆盖选入照片分页和备选方案去重、未选内容不展示、用户标注不证明到访、文本转义与只读来源，地图失败保留点位、重试编号对应、活动更正后刷新与旧快照拒绝，以及照片列表和图片失败恢复、重新开启后移除而旧版本保留。地图图片成功场景使用本地测试图片，后端另以高德响应替身检查仅传确认点、不传计划路线、上限与缓存；不证明真实高德静态地图服务可用。替身验收用于发现界面与真实接口、持久化的集成回归，不证明真实模型、搜索或地图服务的可用性。

运行失败时 `frontend/test-results/` 保留截图和 trace；CI 上传7天有效的失败证据。可用 `pnpm exec playwright show-trace <trace.zip路径>` 查看。测试结果目录已忽略，不提交数据库或截图。
