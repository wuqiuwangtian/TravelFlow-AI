# 账目只读投影契约 0.1.0（实验）

权威仓库：TravelFlow-AI。本目录是首个不可原地修改的版本；改变规则或样例时保留旧版、新建版本目录并由两端明确升级，不能静默跟随main。JSON的schema_version=1仅是样例编码版本，不是同步协议版本。

范围仅为规范化消费／回款的只读汇总。没有规定消费写入、日期、设备身份、冲突、删除、附件或同步协议；通过本契约不能宣称两端已经互通。Python权威实现为 `Itinerary.ledger_summary`，样例由 `backend/scripts/export_ledger_vectors.py`生成和核对。客户端分别实现并验证同一组样例。

金额为正的整分数；跨语言输入及累加结果不得超出JS安全整数范围。pending回款不减少已实付／已到账净额；退款与报销分列，净额允许为负，不强制归零；超额回款按原消费逐笔计算，无法匹配消费的回款仍计入已到账合计。原始输入不得被汇总函数修改；非法金额、枚举或溢出应明确报错，不伪装成零。

样例中repeat仅用于展开压力样本：将第一条消费复制N次，ID为e0至eN-1，回款同样映射expense_id。repeat不是业务字段。样例覆盖14种虚构情况，不包含个人旅行。每项expected是八项整分汇总值。

`manifest.json`记录契约ID、实验版本及文件SHA-256，供两端检测快照漂移；这不是来源签名或兼容性协商机制。未来同步契约另行评审，不能重用此版本号冒充已定义。
