# FE-1 反馈与恢复基础

2026-10-26 起实施，依据 [FE-0 盘点](frontend-audit/README.md)。沿用现有视觉，整体风格、导航布局及手机版分支比较留待 FE-2 讨论。

## 第一组：入口、草稿和旅行列表

- 常用偏好入口独立于服务配置提示；配置读取失败也不遮挡旅行列表。最近旅行使用可键盘访问的真实链接。
- 旅行列表改为可换行的条目，手机不再把名称和操作挤成竖排；搜索忽略旧请求的迟到结果，失败不显示为空数据。
- 列表与对话页复用改名表单；提交原位等待、阻止重复请求，失败保留输入与焦点，重试成功才结束编辑。改名不生成行程版本。
- 归档、恢复、删除具有对象级等待与失败重试，成功以服务端响应为准；刷新失败单独提示，不把已成功的写入说成失败。
- 分支对比区分初始失败、空、加载，切换旅行隔离旧响应；设为当前具有进行状态、原位结果和重试，保留已选择方案。
- 共享 Button 增加忙碌语义、可选进行中文案、键盘焦点及手机最小高度；统一局部 ActionFeedback，不改变业务幂等标识。

验证：生产构建、TypeScript 通过；新增 7 组针对性场景在桌面／手机共 14 项通过，覆盖正常配置、配置失败、键盘入口、改名延迟与失败重试、归档恢复、搜索迟到响应和分支切换隔离。完整既有业务回归在本轮收口时运行。

## 第二组：原位结果与设置保存

- 节点正文复制的成功／失败位于操作旁；失败可手选正文或下载，重试成功清除旧错误。下载只提示已发起，保留真实浏览器下载事件。
- 工程 JSON 导入的校验、失败及成功结果留在工具箱；失败保留原图，成功为待保存、可撤销草稿，不自动执行或采用。JSON 与 Markdown 下载均有发起回执。
- 设置保存状态与重试靠近保存按钮；等待期间锁定表单，失败保留输入，服务端确认后才清除密钥输入。保存成功但状态刷新失败单独说明，读取重试不重复写入。
- 对比方案补充可访问区域；修复重复选择同一旅行会清空已选方案的问题，设为当前后的选择与版本数量保持。

验证：生产构建通过；新增 4 组场景在两端共 8 项通过，覆盖剪贴板失败替代与重试、原位可见性、真实下载事件、无效 JSON、未保存导入、设置失败重试和主方案切换。设置写入及剪贴板权限使用隔离替身，不触及真实环境配置。

## 第三组：等待、辅助操作与回归收口

- 导航标注当前页面或所在旅行上下文；对话与工程归入会话，偏好归入工作台。手机导航布局在 FE-2 讨论。
- 重命名和画布缩放等关键控件扩大触屏命中区，Button 补充键盘焦点与忙碌语义；系统减少动画偏好同时作用于动画、加载图标和程序滚动。
- 局部操作等待超过 12 秒出现仍在等待说明，不自动重发。工程等待提示指出停止入口；停止请求有独立进行、失败重试及结果，避免连点，旧停止响应不覆盖新一轮运行。
- 核对到代理已有 240 秒超时，保留现有边界，不另加可能中断有效生成的通用写入超时。写操作断线或超时时明确“结果尚未确认”，沿用原请求标识和业务恢复，不误报成功或自动重发。
- 首页旅行列表与配置请求各自返回各自显示，配置慢时仍可查看旅行和使用偏好；迟到的旧刷新不能覆盖新结果。
- FE-0 的控件清单和截图作为历史基线保留；扫描与状态探测的默认输出改到忽略的 `frontend/test-results/`，已修复项增加正向回归断言。

验证：本轮累计新增 17 组桌面／手机场景（34 项），**完整 204 项浏览器回归通过**，包含既有账目、原位编辑、附件、冲突、取消、回复丢失重试、工程停止及受保护采用。生产构建、TypeScript 通过；ESLint 0 错误、11 个既有警告。另以独立串行探测复核 11 类路由和空／错／等待／局部结果，输出到忽略目录，不覆盖 FE-0 截图。

本轮交付 FE-1 的反馈基础和优先缺陷修复。下一项为 FE-2 视觉与信息架构讨论；F07 手机长文比较、F08 手机导航布局、模板库／画布关系和旅中回顾层级留在该阶段设计。更广泛组件的视觉与状态迁移随 FE-3/4 收口，不宣称全站升级完成。真实模型／地图、系统剪贴板权限、真机和屏幕阅读器尚未完成实测；本轮用隔离服务、固定模型及配置写入替身验证应用行为。
