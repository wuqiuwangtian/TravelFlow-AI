# 操作与反馈审查附表

与 [主报告](README.md)、[源码入口 CSV](action-inventory.csv) 联合使用。以下按用户能理解的操作族归纳；CSV 是逐处源码清单，包含源文件、行号、路由、标签表达式、事件、禁用／加载／ARIA 属性与共享实现标记。动态文案需结合运行状态理解。

证据等级：**运行**＝本轮浏览器探测；**源码**＝核对实现，未遍历全部状态；**基线**＝加载及布局截图，不能代替该操作完整验收。`loading` 属性缺失不直接判错：本地切换、导航和已经有其他状态回执的操作不需要一律加加载图标。
