跨午夜活动保留在原行程日并标明“次日”。单日调整仍只提示与次日的重叠；用户可发起两天联动，按晚间结束地点及休息时长协调次日。默认预留8小时休息并明确展示，可更改时长与次日出发时刻；无法满足预约、结束期限或超出两天范围时保留原计划，集中提示。预览与应用按分支保存，支持刷新、取消、短确认与失败重试；未来出发位置保持未开始，不作为实际到访或当前记账日期依据。

费用推算中，已结算项目用净消费替代预估；未结算项目取预估与已记净消费中的较高者，避免把押金和整项预估重复相加。人均换算需要明确人数，口径不明时不强行判断是否超预算。

跨天搬移沿用原景点ID和已确认地点，保留人工预算、原始消费、退款与凭证；已付款但未开始的普通景点可以搬移。已有预约、手动固定时刻、住宿／车站／交通、执行记录及指定结束地点不会自动换天。时间轴提供相邻日快捷入口，对话支持地点名、站序和目标站前插入；同名先选择具体活动，刷新、取消和重试沿用预览保护。变化的交通耗时与票价重新校验，不把旧起点的估算直接复制到新路线。

回顾使用无需模型的事实模板，标题和文字随版本保存，不改写执行状态或账本；实际记录变化后保留原文并提示核对。独立导出 Markdown／HTML，不自动附带消费备注、票据或订单资料。旅行照片独立存储清除元数据的展示副本，可标注日期地点、选封面和移除；选入后保存回顾，可导出嵌入照片的离线HTML。照片关联不代表实际到访，未选照片不进入导出，移除不删除旧版本图片。

AI写作默认只将已完成活动作为素材，手写回忆和已记支出需勾选才发送；照片、票据、消费备注、未完成活动和旧朋友圈文案不自动发送。结果仅为待采用草稿，模型仍可能出错，需核对经历和金额；不自动修改原文或发布。生成失败保留编辑状态，生成期间已有新版本时拒绝旧结果；采用后编辑保存，社交短文可复制但不进入普通回顾导出。

旅行结束按方案记录时间与版本；结束后仍可补记，回顾列表按各分支当前版本更新，历史结束版本保持可读。会话归档与结束独立，历史分叉只将新分支恢复为未结束。列表支持分页搜索和只读阅读，返回补记时定位对应方案；回顾列表保留全部已结束方案；跨旅行汇总另见旅行生涯。

旅行生涯按一次会话计一次旅行，只读取当前版本：优先采用已结束主方案，否则采用最近结束方案。每次旅行展示来源依据，不合并备选分支的活动或账目；结束后补记、更换主方案、重新开启和删除后重新读取即更新，会话归档不影响汇总。城市筛选和分页只改变来源列表，总计覆盖全部已收录旅行。

到访城市只来自已完成的非交通活动，排除车站中转、交通、定位起点和计划目的地，缺失城市保持未知；城市名称只合并末尾「市」。已记净消费采用整分金额累加，已到账退款抵减，报销、净支出、待到账回款和无消费记录旅行单独提示。来源卡片链接所选版本回顾和对应分支，可查看照片封面；结束时间只作为记录结束时间展示，没有实际出游日期推断或GPS轨迹。统计本身无需模型和外部服务，足迹地图按需通过后端请求高德。

常用旅行偏好支持主动保存、查看、修改和删除，最多12条、每条60字；不从历史记录自动学习。工作台展示具体内容，新建时默认不选用；勾选后核对当前修订并将副本保存到本次会话，首次对话作为初始需求，普通及流式对话均可覆盖或明确清空。目的地、日期、预算不从偏好补齐，生成后的修改也只影响本次需求。常用偏好删除不改旧旅行副本或历史版本，旧窗口不能覆盖新内容或把已删除偏好写回；冲突载入保留编辑输入，回复丢失可幂等重试。保存本身无需模型；选用后参与该旅行正常的模型和必要检索调用。

生涯照片墙只读取当前采用方案中已保存且选入图文回顾的照片，支持分页、城市筛选、原版本阅读与图片失败重试；未选内容不进入墙。日序和关联活动来自用户标注，不从计划日期、结束时间或EXIF推测拍摄日期，也不据此标记到访。照片城市筛选取来源旅行的实际到访城市，结束／重新开启、照片选择更正、方案切换与删除后重新读取即更新，旧版本仍保留。

城市足迹复用相同来源规则，只取已完成非交通活动；地点列表包括未知坐标的真实记录，静态高德地图仅绘制已确认坐标，相同坐标合并、最多前10个点，不传计划路线或polyline，不补城市中心，不计算实际里程。地图标号可回到来源回顾，全部到访记录独立分页；未配置／超时／服务失败保留地点列表。地图请求校验点位快照，记录变化后拒绝旧图，要求刷新；Key留在后端，照片和统计不调用模型。

高级流程按实际编排展示需求／推荐、检索、生成、确认／修改四个节点；行程、路线和预算仍是生成节点的一组输出。只读接口优先读取当前过程，指定历史版本时仅使用该版本的过程记录及业务快照；缺失或不可读时降级显示已保存数据，不以当前状态补旧版本，不把保留内容当成完整执行日志。真实过程记录中的失败只标注相应节点并给出安全提示，不返回原始异常、工具输入或凭证；重试成功后重新读取即恢复。

单日路线优化只重排固定站点之间的未执行活动，全部地点与 ID 保留；已执行前段、预约、固定时刻、车站与酒店保持原位置，手动交通预算或实付关联的原路段端点受保护。地图与建议排时校验后展示预览；固定项目前交通未知、固定时刻或跨日衔接冲突会阻止应用。预览单独存于本机 SQLite，不增加正式版本或更新过程状态；应用会再次核对版本与 checkpoint，重复请求复用同一结果。其他天、实际账目与回款、凭证关联、人工预算、照片和回顾继续保留；旧回顾按现有事实指纹提示核对。首批不增删景点、不修改全局需求、不重新检索，模型只接收所选天路线必要信息。

节点查看、切换、导出和刷新不执行规划、不增加版本或自动应用待确认操作；处理中可读取已取得的数据并提示刷新。页面提供方案、当前／历史版本选择和对应原对话入口，慢响应在切换后不会覆盖新选择；版本导出指向固定快照，当前过程的导出指向最近保存版本。

## 产品与技术基础

- 普通用户通过固定流程和对话完成规划；更多细节中保留地点、时间、交通和费用等手动调整。高级流程默认进入可自由编辑的生成工程；需求输入、资料检索、AI生成与成稿通过有类型端口连接，支持分支、汇合、局部运行与运行快照。原固定编排保留为观察视图和单日优化入口。
- 前端为 Next.js，后端为 FastAPI，LangGraph 编排收集、检索、生成与修订，SQLite 保存会话、版本和图片。结构化行程承担路线、时间轴、预算与导出的共同数据基础。
- 模型负责理解、推荐与建议，程序负责金额、日期、预约约束及记录一致性。常见多操作消息统一保存，任一步歧义或后续修订失败时整句不落账。
- 本地保存数据和密钥；模型、检索、高德等联网调用会向对应服务发送必要内容。凭证识别由用户主动触发，发送清理元数据后的预览。浏览器定位需授权，不持续跟踪。
- 地图、图片和补充检索失败时已有行程仍有降级展示或修订路径；这不能替代对新信息的核实。
- 对话失败时保留输入，页签内刷新可恢复分支草稿；同一次发送通过请求回执和图完成标记核对结果，避免回复丢失后重试再次记账。使用快捷建议或候选按钮期间，原输入及其重试信息仍保留；快捷操作再次断流、刷新后也能分别恢复。编辑文字后发送、成功后重新发送属于新操作。草稿暂存在浏览器页签，正式记录与回执保存在本地 SQLite。

## 尚未补齐的能力

1. **复杂表达**：日期、金额、活动站点、地点候选与同日同名消费已有待澄清承接；失败恢复与同次发送防重复已有验收。复杂复合句、同一消费下多笔同类回款和“离酒店近”等模糊空间关系仍需具体描述。
2. **多日联动**：相邻两天的时间协调、同城景点搬移及预算／消费关联已接入；跨城、固定安排换天和更长多日重排尚未完成。两天预览不与记账／预约录入混合执行；天气和营业等实时变化尚无持续监测闭环。
3. **真实旅行验证**：缺少完整多日实走样本和多模型长期验证；地图命中、参考图与检索结果不代表真实可预订或准点可达。
4. **旅后内容**：实际活动与净消费汇总、回顾／照片／封面／AI文案、独立导出、结束与重新开启、回顾列表已形成核心闭环。旅行生涯首版已实现实际汇总、城市筛选与来源追溯，常用偏好主动保存和选用、生涯照片墙和确认坐标足迹已接入；实际拍摄时间轴、GPS跟踪及偏好自动推断尚未实现；实际足迹只来自已完成活动，结束不会把计划与进行中活动写成已到访，也不自动结算费用。
5. **附件与协作**：文字导出不打包票据，未保存上传仍占旅行配额；尚无孤立图片清理界面、多人协作或个人分账。

6. **高级节点**：已实现自由生成工程、独立参数、类型连线、分支汇合与运行快照；成稿可整理预览并受保护地采用到正式行程；冲突或基线变化时拒绝更新。景点与日程、路线校验及预算汇总使用行程／预算端口流转，采用纯结构化成稿无需再次调用模型；预算可按明确设置补充缺项饮食、住宿、往返交通与备用金，保留已有金额和未知分项，采用前结合原记录重算；地图结果不验证预约和营业。个人模板支持命名、更新和跨旅行复用，保存时默认清空需求输入，节点指令及明确保留的固定文字仍会复用；不附带来源运行或实际记录，尚无模板版本回退和云共享。景点筛选基于已有每日安排，路线仅在确认坐标与固定分段内减少直线折返，完整地图耗时增加或校验超时则保留上游；独立候选池和规则分日已拆分，同池支持不同节奏与天数；首版要求同城，按停留与缓冲平衡，可按明确同城坐标分组，未明确时沿用时长方案，不补造跨城交通。生成共用系统服务配置，未提供自定义脚本或单节点服务商选择；日常对话过程观察仍不是完整运行日志。
