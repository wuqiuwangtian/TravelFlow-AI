# FE-4 收口：三主题、剩余控件与设计检查

2026-10-28，本轮前端升级的既定实现与隔离回归已收口。默认 A、D3／M1、C1／P1、R1／W1 和电脑松弛／手机紧凑保持一致；设置中正式开放三套配色。

## 本批交付

- **外观设置**：A 暖纸墨绿为默认，B 冷白深蓝、C 深灰绿即时切换，只存当前浏览器。外观与模型、检索、地图表单独立，切换不会保存服务配置、清空密钥草稿或生成旅行版本；服务读取失败时仍可使用。
- **持久化与首屏**：固定引导脚本在正文出现前读取白名单主题，避免先显示 A 再跳到 C；非法值回退 A，不执行存储内容。刷新、页面导航和同源标签页同步主题；删除或清空存储回到 A。浏览器拒绝存储或额度不足时，当前仍能切换，并明确说明未保存，刷新可能回退。
- **语义颜色**：旧页面 506 处颜色用法迁入共享颜色，覆盖旧路书、行程详情、原流程检查、单日优化、工程参数／产物、候选、预算、合并、模板与采用弹窗。移除临时旧类覆盖，Markdown 正文、表格、代码、引用和弹窗遮罩使用同一批 token；流程观察不再固定为深色面板。
- **控件反馈**：保留已有等待、防重和失败草稿机制，补齐折叠项、旅中导航及购票入口的共享反馈与焦点，触屏字段使用 16px 和 44px 入口。普通面板统一轻圆角，节点和端口继续保持真实坐标，减少动画下保留可见状态。
- **用户原文**：不清洗历史对话、模型内容或照片说明。去除导出免责声明固定警示 emoji，保留原核实提示；正文中用户自己的 emoji 继续保留。
- **持续约束**：`npm run check:design` 扫描正式前端源码，检查语义颜色与产品编写的 emoji；配色及示意色集中在 `styles/tokens.css`。检查已接入 CI，后续新界面沿用同一规范。

## 验证

- 类型、生产构建与格式检查通过；ESLint 为 0 错误、11 条既有警告。设计约定检查通过，覆盖 68 个前端源文件。
- 新增 `theme-settings.spec.ts` **20 项**桌面／手机专项通过：默认与系统偏好、首屏主题、非法存储、跨标签同步、拒绝存储／额度不足、配置故障、草稿保护、三主题正式页面、版本不变、空间控件与模板弹窗。
- 三主题分别遍历工作台、旅行列表、偏好、设置、比较、指南、回顾列表与阅读、生涯、旅行工作区、自由工程和原流程检查。选定标题、控件、说明及路书段落检查合成背景后的文字对比度，阈值 4.5；这不是完整可访问性认证。
- 最终生产构建的完整串行浏览器回归 **316 项通过（5.8 分钟）**。其中原有主任务覆盖普通旅行的生成、修改、记账、刷新和导出，以及高级工程的模板、节点编辑、运行、产物核对与正式采用；等待、鉴权失败、并发、取消和回复丢失继续验证。
- 导出相关后端测试 **12 项通过**，其余 527 项未在本批重跑；导出公共文件的 Ruff 检查与格式通过。没有修改后端接口或账目规则。
- Windows 原生 Edge 在 **1440×1000／390×844** 视口核对 A／B／C、服务草稿、刷新恢复，以及 C 下路线、完整路书、流程检查、画布和模板弹窗；无页面脚本错误或横向溢出，[16 张原始截图](design/themes/README.md)已保存。专用 QA 前后端已关闭。

测试使用临时数据库、固定模型／检索／地图替身，不读取个人旅行、改写个人环境配置或调用真实密钥。主题操作之外的旅行来源、版本和导出走真实本地接口；服务故障与存储限制由测试控制。Windows 手机视口不代表手机硬件实测，未重新验证真实外部服务可用性，也未发布部署或宣布正式版本。

## 完成边界与后续

FE-0 至 FE-4 本轮实现与上述自动化验收已完成，不能据此承诺任意网络、模型和真实旅行都无问题。后续回到普通用户的少操作主流程验收：从未定目的地、形成完整建议、集中处理必要澄清，到途中修改与实际消费、回顾和导出，按可复现的阻塞安排修复；继续保留真实服务和多日实走的待验证边界，不优先叠加新节点或设置。
