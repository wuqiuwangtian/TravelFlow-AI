# FE-4 第一批：工作台、旅行列表、设置与偏好

2026-10-27，沿用默认 A、C1 组件与电脑松弛／手机紧凑密度，把普通旅行的入口和配置页面迁入共享样式。

## 本批交付

- **工作台**：移除营销渐变横幅与等权旅行卡片，明确开始旅行、可选常用偏好、最近旅行三层内容。偏好默认不勾选，最近展示六条并提供全部旅行入口；已有旅行不必等待服务配置读取成功后才能显示。配置不足时使用面向用户的提示，具体配置进入设置完成。
- **我的旅行**：搜索、活跃／归档切换、打开、改名、归档／恢复及删除采用同一套控件和原位反馈。保留行级等待和失败重试、旧查询响应隔离、改名草稿与取消后的焦点恢复；长名称和手机操作区可自然换行。
- **设置**：模型、检索、地图和生成偏好提供分区直达，分区跳转不重建表单。静态标题改为 Lucide 图标，移除 emoji；配置保存路径放入可展开说明。输入控件有明确标签，说明和文档链接不再包在输入标签中。
- **配置反馈**：显示未保存更改，模型列表及连接测试在对应分区反馈，并说明依据已保存的配置。保存失败保留草稿；确认保存后清空密钥输入。保存成功而状态读取失败时保留原有区分，后续刷新不覆盖用户新输入的草稿，也不重复写入设置。
- **常用偏好**：电脑把编辑区与已保存内容并排，手机先编辑再核对已保存内容。保存、删除、载入最新偏好分别显示等待，失败与冲突在编辑区附近提示并恢复焦点；载入新版本仍保留原输入。现有旅行持有创建时副本的语义继续保留。

新页面复用 `styles/pages.css`、语义颜色和共享按钮、卡片、错误及状态组件；手机表单字号至少 16px，触屏控件至少 44px。共享改名输入也采用同一套字段样式。本批没有修改后端接口、配置文件格式、旅行数据、规划或账目规则。

密钥只使用密码输入框承接新值，不回显已有值、不写入浏览器草稿存储；留空保留已有密钥，高德显式勾选移除时才发送空值。测试使用虚构输入，不在交付截图中展示密钥。

## 验证

新增 `account-pages.spec.ts` 的 14 项电脑／手机检查，覆盖开始旅行与最近链接、默认不选偏好、设置直达与长服务商名称、密钥失败保留与留空语义、保存后的刷新恢复、连接测试及模型列表、偏好删除等待和长旅行名称。结合原有反馈、可访问性和偏好场景，专项 **52 项通过**；生产构建、类型和格式检查通过，lint 为 0 错误、11 条既有警告。

Windows 原生 Edge 在 1440／390 视口核对四页排版、列表进入、设置分区与草稿、偏好选用及编辑，均通过，没有页面脚本错误和横向溢出。[原始截图](design/account-pages/README.md)已保存。最终正式构建的完整串行浏览器回归 **270 项通过**，包括新增 14 项。专用 QA 服务已关闭。

验收使用独立临时数据库与固定模型、检索、地图替身；旅行列表和进入旅行使用真实本地接口。设置读取／写入、连接测试、模型列表及专项偏好响应使用替身；原有偏好集成场景继续核对真实本地版本及创建时副本。没有读取个人旅行、改写个人环境文件或调用真实服务商，手机视口核对不等同于手机硬件实测。
