使用指南

三步开始，不需要任何技术背景
1

启动服务

双击 start 脚本，等浏览器自动打开即可

2

配置模型

在「设置」里选一个模型服务商并填入 Key；不想折腾可选本地 Ollama

3

开始规划

回到工作台点「新建旅行」，说出你的目的地就行

API Key 是什么？去哪里申请？
Key 相当于模型服务的「门票」。推荐 DeepSeek（性价比高，官网可申请，充 10 元能用很久）。
如果你完全不想注册任何服务，可以在设置里选「本地 Ollama」，模型跑在自己电脑上，完全免费。
检索服务要花钱吗？
有三种免费方案：
① DuckDuckGo：完全免费，不需要任何 Key，直接在设置里选它就能用；
② 百度千帆：每天免费 100 次，个人用完全够；
③ Tavily：每月免费 1000 额度，约能生成 166 份路书。
为什么生成一份路书要等十几秒？
系统需要实时联网检索交通、景点和避雷信息（3 路并行检索），再让模型基于这些真实资料生成内容。 这是为了保证信息真实，而不是让模型凭空编造。
路书里的信息可靠吗？
所有事实性信息（票价、开放时间）都标注了来源编号，鼠标悬停可看来源。 引用链接由系统直接从检索结果获取，不经过模型改写。
另外每份路书都会标注「信息检索时间」，出行前建议再核实一次最新价格。
「分支」是干什么用的？
如果你拿不定主意，可以从同一个起点生成几个不同方案（比如「亲子版」和「美食版」）并排对比。
改来改去发现还是最初那版好？在版本历史里点最早的版本「回到这里」就行，原来的版本不会丢。
数据会上传到云端吗？
不会。所有会话、路书、配置都保存在你电脑上的一个数据库文件里。 只有调用大模型和检索服务时，必要的文字才会发送出去。
