# FE-4 第二批：回顾、照片与旅行生涯

后续进展：2026-10-28，三主题与本轮全站收口已完成，最新结果和剩余边界见[收口记录](frontend-themes.md)。下文保留该批交付时的覆盖和验证。

2026-10-28，沿用默认 A、C1、D3／M1 和两端密度，将回顾列表、只读阅读、旅行内回顾编辑、照片写作及旅行生涯迁入共享样式。

## 本批交付

- **回顾列表与阅读**：列表采用有层级的记录行，封面与标题、实际记录、阅读和补记入口并列；阅读页使用统一纸面、正文与导出控件。搜索等待时先显示进行状态，避免残留上一次结果；分页、历史版本及只读语义沿用现有接口。
- **原位保存**：编辑区上方保留可见的保存操作和未保存提示，长照片表单也可直接保存。等待、失败与成功回执靠近保存按钮；服务端确认后才说明已保存，错误保留文字、照片与选择。结束／重新开启旅行的反馈跨版本切换仍可见，实际账目和历史回顾继续保留。
- **草稿保护**：同一版本保存后的延迟读取不会覆盖用户后来输入的新文字；读取失败可就近重试并保留输入。新版本继续按原有版本边界加载，生成与保存沿用来源指纹和并发保护。
- **照片查看**：`RecapImage` 在编辑、列表、阅读和生涯中复用，预览尺寸稳定，完整查看按保存图像比例显示并限制高度。支持键盘打开、Esc／按钮关闭、焦点返回和加载失败重试；照片说明中的用户原文保留。横图、竖图和方图使用同一套容器规则。
- **照片编辑**：按编辑区实际宽度排列，桌面 D3 窄栏保持单列；上传等待防重，部分失败保留已上传内容。选入、封面和移除仍先修改草稿，保存回顾后才形成关联；历史图片及既有额度规则保留。
- **AI 写作**：生成等待、失败、采用和丢弃有独立反馈。生成不覆盖原文，采用填入编辑区，保存后才写入版本。素材勾选仍由用户主动决定，照片和票据不随界面改版发送给模型。
- **旅行生涯**：移除深色统计大块和空封面装饰，使用统一排版、筛选、来源链接与照片查看。足迹图失败时仍能查看记录，手机地点列表使用正常页面滚动。到访、方案去重和净消费口径沿用服务端实际记录，不把照片标注或计划地点当作到访。

本批复用 `styles/pages.css` 与共享按钮、反馈、字段；`styles/history.css` 承载回顾和照片规则。图片按钮、上传控件也提供悬停、按下、焦点和减少动画支持。后端接口、图片存储、账目计算和规划规则沿用现状。

## 验证

原有回顾、照片、写作、结束旅行及生涯 **36 项**集成场景通过；新增 `history-workspace.spec.ts` 的 **14 项**电脑／手机专项通过，覆盖原位失败与防重、部分上传、横竖图、完整查看及焦点、AI 草稿分层、跨版本成功反馈、延迟读取保留新输入、历史来源和长表单保存可见性。

类型、正式构建与格式检查通过，lint 为 0 错误、11 条既有警告。Windows 原生 Edge 已在 1440／390 视口验证列表、阅读、编辑、生涯、完整照片查看及真实保存失败／重试；[原始截图](design/history/README.md)已保存。最终正式构建的完整串行浏览器回归 **284 项通过**，包括新增 14 项。专用 QA 服务已关闭。

验证使用临时数据库、固定模型／检索／地图替身与人工生成的比例测试图，不读取个人旅行、不加载个人环境配置或调用真实密钥。照片上传、回顾保存和版本变化走真实本地接口；特定失败和 AI 草稿响应由测试控制。图片是明确标注的验收样本，手机视口核对不等同于手机硬件实测。
