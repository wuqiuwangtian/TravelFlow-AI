# FE-3 第四批：W1 高级工程工作区

沿用 [统一设计规范](design/SYSTEM.md)与用户确认的 W1：画布在左，参数及独立产物在右。此次迁移保留正式 studio 的业务实现，不使用选型样稿替换真实节点或运行结果。

## 已迁移的路径

- **电脑工作区**：画布占主区域，右侧检查区独立滚动；较长的预算、筛选和生成参数不会把画布推走。保存、运行、停止和结果反馈保留在固定操作栏，操作栏高度变化时自动给画布及检查区留出空间。
- **节点工具箱**：改为紧凑的横向工具条，保留全部 12 种节点和工程 JSON 导入／导出。8 套默认模板、个人模板的载入与编辑保持；打开模板库后定位到模板，选择后返回画布。
- **检查区**：当前节点选择与“参数／产物”定位入口固定在上方。两个入口滚动到同一检查区内的相应内容，不通过卸载组件切换；已有参数草稿、候选定位、结构化数据、来源、正文复制／下载和正式成稿采用流程继续使用原实现。
- **画布手感**：沿用既有节点坐标、连线、平移、缩放和聚焦。节点及端口的悬停／按下只改变颜色、边界和阴影，不位移或缩放按钮；连线悬停或键盘焦点以加粗和虚线反馈。拖动时不因容器变化自动重置视角，保存状态预留固定宽度，避免开始拖动后文字变化挤动操作栏。
- **键盘移动**：聚焦节点标题后，方向键移动 10 个画布单位，Shift 加快至 40；仍走原工程草稿、撤销与保存逻辑。快照及运行中的节点可选择查看，移动和改线被禁用。
- **手机检查**：画布、参数与产物、工具箱提供直达入口，工程保持同一份状态。选中和拖动节点不强行跳离画布；用户主动进入检查区后，可以继续编辑或查看产物，再返回画布。普通旅行的 M1 今日路线不受影响。
- **手机弹窗**：运行记录的长选项在容器内收缩，采用与模板弹窗按实际视口限定边界；关闭、核对、采用及失败重试保持可操作。宽度检查以页面可见宽度为依据，避免手机浏览器把溢出后的 `innerWidth` 当成正常屏幕宽度。

本批没有增加后端节点类型或改写执行、缓存、分支、采用、账目与请求幂等性。改变参数后的旧产物仍标记待更新，运行记录及快照继续可追溯；运行工程不自动采用为正式行程。

## 共享样式

高级工程、模板编辑及成稿核对弹窗使用默认 A 的纸面、墨绿和 C1 组件规则。端口按数据类型使用共享变量，分别表示文本、资料、候选景点、行程和预算；不是每种节点另造一套主题。B／C 的全站主题设置仍随剩余页面迁移收口。

可操作按钮、按钮式链接与展开控件提供悬停、按下、焦点、禁用及等待反馈；空间控件保留坐标。减少动画时停止位移与缩放，定位也遵循系统偏好。绘图端口随画布缩放，手机可通过聚焦／缩放，或使用画布下方的大尺寸连线选择器操作，不要求靠小端口完成所有连接。

## 验证记录

`studio-workspace.spec.ts` 新增 12 项电脑／手机检查：真实布局与窄屏、长参数独立滚动、双向查看与草稿、无隐式写入、独立产物与正式版本隔离、节点悬停不位移、键盘移动／撤销／保存、端口即时反馈、只读快照、保存等待和失败，以及减少动画。旧高级工程测试继续核对原有拖动、类型连线、缓存与局部重跑、模板、定位、合并、预算及正式采用。

类型、生产构建与格式检查通过，lint 为 0 错误、11 条既有警告。手机采用／模板／工作区专项 **15 项通过**，最终生产构建完整串行浏览器回归 **242 项通过**。手机弹窗曾因运行记录长选项撑宽页面而遮挡关闭按钮，已修复，并补上实际视口与真实关闭操作的回归检查。

Windows Edge 另以 1440／390 视口实测分支运行、独立产物、手机聚焦、草稿保留及正式版本不被自动采用，均通过且没有页面脚本错误。[原始截图](design/studio/README.md)展示电脑右侧产物与手机参数／画布；专用 QA 服务已关闭。

检查使用专用临时数据库、固定模型、检索和地图替身，不加载 `.env`、不使用真实 API Key 或个人旅行，不证明真实服务商的持续可用性。没有替换或清空已有数据库。
