## 一句话方案

把旧项目重构为**小白友好的本地 Web 旅行助手**：Next.js 16 前端 + FastAPI/LangGraph 1.x 后端，依赖全部锁定版本，LLM 同时支持云端与本地部署模型，检索源可插拔，导出 Markdown/HTML，支持源码与 Docker 两种部署。

## 二、已实测验证（可行性无需担心）

| 机制 | 实测结论 |
| :--- | :--- |
| Python 3.13.13 + LangGraph 1.2.14 | ✅ 可安装、可运行 |
| **显式入口路由**（修复 refiner 不可达） | ✅ `status=reviewing` 时直接进入 `refiner` |
| **SQLite Checkpointer** 断点续聊 | ✅ 模拟进程重启后状态未丢失 |
| **结构化输出**（根除 KeyError） | ✅ `with_structured_output` 可用 |
| **引用编号 → 真实 URL 替换** | ✅ 可用，且能检出 LLM 编造的引用编号 |
| Jinja2 单文件 HTML 导出 | ✅ 可用（内联 CSS，可离线打开） |
| 检索 SDK 可用性 | ✅ `tavily-python` / `ddgs` / `qianfan` 均有官方包；博查用 httpx 直调 |

## 三、你将得到什么（阶段③的验收标准）

| 能力 | 验收方式 |
| :--- | :--- |
| **计划确认/修改闭环可用** | 第 2 轮说「改第二天」→ 只进 `refiner`，**不重新检索** |
| **引用真实可信** | 文件里的 URL 全部来自检索结果，程序透传，LLM 接触不到 |
| **信息不过时** | query 年份动态注入 + 路书标注「信息检索时间」 |
| **并发不阻塞** | 3 个并发请求总耗时显著小于串行 |
| **一键启动** | `./start.sh` 或 `docker compose up -d` |
| **模型自由切换** | 改 3 行配置即可从 DeepSeek 切到本地 Ollama |
| **零成本可跑** | `SEARCH_PROVIDER=ddg` 无需任何 Key |
| **依赖可复现** | `uv.lock` + `pnpm-lock.yaml` 入库，锁定全部版本 |
