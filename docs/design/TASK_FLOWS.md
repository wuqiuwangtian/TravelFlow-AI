## 四条可实际试用的路径

1. **对话修改**：发送“下午少走一点，留出喝茶时间”。本地演示将下午步道改成茶歇，步行示例从 3.8km 到 1.2km，增加茶歇预估 ¥48。比较 R1 与 R2；等待时阻止重复提交。勾选失败演示后保留原路线和输入，可再次发送；不支持的自由指令明确说明样稿范围，不冒充真实模型理解。
2. **路线执行**：选择路线或示意地图上的站点，导航响应说明默认上一站到当前站；首站从当前位置开始。标记完成后选中下一处未完成站点，路书同步状态；也能恢复未完成。没有申请位置权限或真正打开地图导航。
3. **原位记账**：在饮食、住宿、交通、门票原行点击实付，表单直接展开并聚焦。保存后结算项按实付替代预估，其余继续保留预估；自定义实际费用也在同一清单。预计总支出、已记消费和预算余量／超额使用整数分计算。撤销行程修改保留已记消费，包含已结算的茶歇，不把撤销规划当成撤销记账。
4. **自由节点工程**：三套默认模板分别为景点池到分日／预算、快速成稿、两路景点合并；载入后结构仍可编辑。可拖标题、键盘移动、平移与缩放、添加／删除节点、连接／断开端口、撤销工程编辑、修改指令、检查独立产物。端口使用现有 studio 的文本／候选景点／行程／预算概念，拒绝不匹配连接和循环。参数草稿在切换节点时保留；保存后仅失效本节点与下游，模拟运行展示重算与复用数量。

实付编辑与行程修改相遇时先保留当前金额草稿，提示在原位保存或取消，避免重绘把草稿清掉。修改中的新对话草稿同样保留。没有后端回执的演示结果都标注为本地模拟。
