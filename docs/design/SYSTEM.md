## 共享变量

使用语义变量表达页面背景、纸面、浮层、正文、次要文字、边界、强调色及状态，禁止在新业务页面另造一套颜色。A 的基线来自第三、四轮样稿：背景 `#e8e5de`、纸面 `#f8f5ee`、内容面 `#fffdf8`、正文 `#292e29`、次要文字 `#687064`、边界 `#d9dbcf`、强调色 `#355744`、强调浅底 `#e5ebdf`。

B／C 替换同一批颜色变量，不另建导航和组件。主题设置及持久化接入时，必须核对旧页面的硬编码颜色；不能把有浅色文字残留问题的深色页面当作已完成主题支持。FE-3 第一批先提供三主题变量，正式界面采用默认 A，设置入口随页面迁移接入。

正文沿用系统中文无衬线栈，不依赖远程字体。对话正文 16px，输入框 16px，主标题约 24px／手机 22px，区块标题 18px，次要信息 12–13px；信息不能只靠颜色表达。后续针对真实页面调整层级时，优先补共享规范，不通过每页零散指定字体解决。

间距以 4px 为步进，常用 8／12／16／24／32px；面板内距电脑约 24px、手机约 18px。圆角默认 8px；时间线节点、地图点位可保持语义所需的圆形。避免巨幅渐变、等权卡片网格和无意义装饰。

## 交互状态

- 普通按钮、图标按钮、按钮式链接均有悬停、按下、焦点、禁用和等待状态。C1 悬停约 160ms，按下约 100ms；轻抬约 1px、按压缩至约 0.975。主按钮采用实色强调，不使用旧的蓝绿渐变。
- 图节点、地图点位等空间对象保留颜色／边界反馈，避免位移或缩放改变交互坐标与连线。共享组件为此保留空间操作变体。
- 减少动画时停止位移／缩放与持续旋转，保留状态文字和边界反馈。键盘焦点清晰，触屏无需悬停也能找到入口。
- 加载立即反馈并防止重复提交，成功以真实回执为准；失败保留草稿和已有结果，重试保持原有幂等语义。不能把动画当作请求成功。
- 实付、预估、预算余量／超额在同一项目与上下文呈现。金额使用已有整数分与服务端口径，样稿计算不可代替正式账目规则。
- 产品编写的界面不出现 emoji，沿用 Lucide；不清洗用户输入、历史对话、照片或模型原始内容。

## 迁移批次与完成边界

1. **共享基础**：语义 token、C1 按钮／卡片／反馈、应用外壳。保留现有组件参数与请求状态，先核对加载／失败／禁用和移动端。
2. **普通旅行**：D3／M1 布局、对话与路线联动、R1 正式应用／撤销、原位费用、P1 图片与地图。保留历史版本、实付、自定义项和草稿。
3. **高级工程**：W1 检查区与统一样式，保留现有节点类型、端口校验、分支、模板、产物和运行恢复。
4. **全站收口**：主题设置与持久化、剩余设置／列表／生涯／回顾／帮助等页面，以及原生按钮与按钮式链接、无 emoji 和全部状态的统一检查。

共享组件迁移完成不意味着原生按钮、旧硬编码颜色、D3／M1、R1 或 W1 已全部落地。各批提交记录实际覆盖页面、验证结果与剩余事项；业务路径继续使用正式后端与隔离测试数据验证，不读取或改写个人旅行数据。
