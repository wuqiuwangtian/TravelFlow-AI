# FE-3 第一批：正式共享设计基础

后续进展：2026-10-28，三主题与本轮全站收口已完成，最新结果和剩余边界见[收口记录](frontend-themes.md)。下文保留该批交付时的覆盖和验证。

依据已确认的 [设计规范](design/SYSTEM.md)。R1 直接更新可撤销、W1 画布右侧检查已进入选型记录；本批将正式前端的共享样式接入规范，完整工作区与业务迁移随后进行。

## 本批覆盖

- `frontend/styles/tokens.css`：A／B／C 同一组语义配色变量、8px 圆角、160ms／100ms 反馈，以及电脑／手机的基础间距。正式界面默认 A；B／C 目前只是基础变量，尚无全站主题切换与持久化入口。
- `frontend/styles/components.css` 与 `components/ui.tsx`：共享按钮、卡片、加载、原位状态、错误、空状态及标签。主按钮改为墨绿实色；按钮尺寸、圆角、悬停、按下、焦点、等待、禁用与减少动画共用规则。普通命中区至少 40px，粗指针至少 44px。
- `Button` 保留既有 variant／size／loading／loadingLabel、事件与 DOM 属性；loading 期间仍禁用。新增 `motion="spatial"` 为地图点位和节点等空间对象提供不改变坐标的反馈，尚未将旧画布控件批量替换。
- `app-shell.tsx` 与根布局：正式应用默认暖纸背景、统一墨绿品牌、轻边界顶部导航；导航链接有悬停／按压／焦点反馈，保留路径与 `aria-current` 上下文。正文系统字体栈保持可读性。
- 现有 brand 色工具类接入语义变量；普通页面中其他旧颜色与原生控件随下一批逐一迁移，避免误把全局换色当成完成整站改造。

本批不修改业务请求、分支和历史版本、草稿存储、费用账目或个人环境文件；测试使用隔离数据库与固定服务替身。

## 验证

```sh
cd frontend
npm run typecheck
npm run lint
npm run build
PLAYWRIGHT_BROWSERS_PATH=/tmp/travelflow-browser node node_modules/playwright/cli.js test --workers=1
```

类型与构建检查通过；lint 为 0 错误、11 条既有警告。串行浏览器完整回归 **210 项全部通过**（原有 204 项＋新增 6 项），用时约 5.2 分钟；未再出现 SQLite 锁冲突。最后一个空间变体禁用态守卫调整后，共享基础 6 项定向复核再次全部通过（约 8 秒）。

新增 6 项浏览器检查覆盖实际悬停与按压、键盘焦点、触屏尺寸、等待禁用与重复点击、失败草稿和重试、共享主按钮三主题对比度及减少动画。三主题检查只覆盖基础组件，不能作为旧页面深色主题适配完成的证据。

初次以 4 workers 并行运行时，隔离 SQLite 出现持续锁冲突，停止该次运行并重建服务；本轮以单 worker 重跑完整集合，结果单独记录，不将中断场景算通过。没有调整生产数据库或为了测试绕开业务校验。
