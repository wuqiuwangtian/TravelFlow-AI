# FE-3 第五批：费用与旅中操作

2026-10-27，沿用默认 A、C1、电脑 D3 与手机 M1，将费用、消费明细、退款报销、凭证、预约与途中调整迁入共享组件。

## 使用变化

- **先看费用结论**：预计总支出与预计超预算／余量放在汇总上层，清单预估与已记净消费作为核对依据。未定价项目继续说明，不能把未知费用算成节省；退款到账冲减消费，报销回款单列。
- **原位编辑**：实付仍在对应预算项目内填写。自定义预估紧接添加入口，消费与回款的更正在原明细条目展开；保留付款日期、关联站点、备注和图片凭证。取消不写入版本。
- **原位结果**：提交时共享按钮显示等待并禁用重复操作，附近显示保存状态；失败保留草稿并在当前操作附近恢复键盘焦点，不再滚到行程顶部找错误；新增消费、回款和自定义项重试沿用原请求标识，其他操作保留已有版本保护。服务端确认后展示成功；若写入已完成但界面更新失败，明确提示刷新核对。模型鉴权失败保留设置入口。
- **回款与预约**：待到账、标记到账、编辑与移除回款继续使用原账本规则。预约记录、清除与跨午夜调整保留原时间约束，更新成功后仍能看到反馈；移除预约记录不取消外部订单。
- **手机使用**：消费和回款明细不再另设一层滚动框；长下拉选项和表单可在容器内收缩，手机输入字号 16px、触屏控件至少 44px。费用类别按实际容器宽度排列，电脑右侧窄栏保持单列。导航默认上一站，只有主动定位才申请当前位置。
- **凭证**：上传、识别、移除和查看复用同一套动效与焦点规则；缩略图按原比例完整显示。识别结果仅填入草稿，仍需保存消费才形成账目。

金额仍由原服务端整数分、预算与回款口径提供。本批没有改写数据库、费用结算规则、请求幂等性、地图服务或外部订单能力，也没有改变用户图片及模型内容。
