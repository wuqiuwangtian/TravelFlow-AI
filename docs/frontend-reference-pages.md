# FE-4 第三批：分支对比与使用指南

2026-10-28，沿用默认 A、C1 与两端密度，统一比较与帮助页面。桌面保留并排阅读，手机按方案纵向查看，不把三个窄列缩进手机屏幕。

## 本批交付

- **比较入口**：使用有标签的旅行选择、统一方案按钮与明确的三份上限。选满时说明取消方式，全部取消后仍能从上方重新选择。方案标题与用户原文保留；产品编写的星标字符改为 Lucide 与“当前”文字。
- **独立结果**：各分支分别读取最新路书，较慢的请求不阻塞其他列。失败只重试本列，不重新加载其他正文或重置已读位置；尚无路书使用普通空态，不冒充服务故障。
- **来源与切换**：显示版本号与来源数量，提供携带分支标识的继续编辑入口。“设为当前”仍调用正式接口，等待、失败重试与确认结果靠近该方案；保留选择、各分支及历史版本，不因切换默认方案生成版本。
- **异步隔离**：切换旅行立即移除上一份比较；旧分支列表、路书与设置回执不能覆盖新选择。上一份旅行的设置操作尚在进行时，说明等待原因。
- **两端阅读**：电脑按所选数量并排，正文区可聚焦滚动；手机使用正常页面滚动，并提供方案跳转与返回选择。长名称、链接及代码在容器内换行或滚动，不撑宽实际视口。
- **使用指南**：按出发前、旅途中、回来后三段提供操作与正式页面入口，覆盖高级工程、分支版本、故障重试、地图图片、批量记录、来源核对和数据存放。生成、采用、保存分别表达；不再承诺固定生成秒数、必然准确或只选本地模型就所有功能离线。
- **交互规范**：使用共享按钮、链接、反馈及语义颜色。常见问题沿用原生折叠、键盘操作与清晰焦点，补齐悬停／按下及减少动画；外部服务链接说明新窗口。

`styles/reference.css` 承载比较及指南的布局与阅读规则，复用 `styles/pages.css` 和共享组件；仅在比较正文内覆盖旧 Markdown 配色，全站 Markdown 与剩余硬编码颜色继续列入收口。没有改动后端协议、服务商、账目计算或节点能力。

## 验证边界

使用临时数据库与固定服务替身，不读取个人旅行、不调用真实服务密钥。新专项 `reference-pages.spec.ts` 覆盖独立慢请求、单列失败重试、选择上限与空态、切换旅行的迟到响应、真实主方案切换与版本不变、分支来源跳转、长内容实际视口、指南键盘与减少动画。失败和迟到响应由测试控制，正式主方案切换与旅行来源使用真实本地接口。

新增双端专项 **12 项通过**；既有比较与反馈场景在首轮专项中通过。类型、生产构建与格式检查通过，lint 为 0 错误、11 条既有警告。Windows 原生 Edge 已在 1440／390 视口验证比较读取、单列失败重试、正式主方案切换、来源跳转、指南章节与键盘折叠；[9 张原始截图](design/reference/README.md)已保存，没有页面脚本错误或横向溢出。手机视口核对不等同于手机硬件实测。

最终生产构建的完整串行浏览器回归 **296 项通过（7.3 分钟）**，包含新增 12 项及原有旅行、费用、回顾和自由工程场景。本轮独立 QA 前后端已关闭。
